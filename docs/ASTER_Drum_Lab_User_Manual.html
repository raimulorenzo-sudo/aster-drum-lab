概要

ASTER Drum Lab は、自分のサンプルを読み込み、叩き、磨き上げて、完成したドラムキットへと仕上げるためのサンプラー型インストゥルメントです。各パッドは独立した音作りチェーンを持ち、レイヤーを重ねて厚みを出したり、ベロシティで音色を切り替えたりできます。

02 Getting Started

インストールと起動

VST3 / AU プラグイン、およびスタンドアロンアプリに対応しています。お使いのDAWに合わせてフォーマットを選んでください。

対応フォーマット

フォーマット対応環境
VST3Windows / macOS — 主要DAW全般
Audio Unit (AU)macOS — Logic Pro / GarageBand / Live 等
StandaloneWindows / macOS — DAW不要で単体起動

インストール先

macOS

  • VST3：~/Library/Audio/Plug-Ins/VST3/ASTER Drum Lab.vst3
  • AU：~/Library/Audio/Plug-Ins/Components/ASTER Drum Lab.component
  • Standalone：ASTER Drum Lab.app（アプリケーション）

Windows

  • VST3：C:\Program Files\Common Files\VST3\ASTER Drum Lab.vst3

起動の手順

  1. インストーラ（または各ファイル）を上記の場所へ配置します。
  2. DAWを起動し、必要に応じてプラグインを再スキャンします。
  3. インストゥルメント・トラックを作成し、ENIGMA > ASTER Drum Lab を選択します。
  4. パッドにサンプルをドラッグ＆ドロップして完了です。
NOTE AU版が一覧に出ないときは、プラグイン検証をやり直すかDAWを再起動してください。Logic Pro は初回起動時に AU 検証を自動実行します。

マルチ出力で使う場合

各パッドを個別の出力へ送るには、DAW側でマルチアウトプット構成で読み込み、OUT MODE を 16 / 32 / 48 Outs に設定します（→「15. ルーティング」）。

TIP まずはスタンドアロン版がおすすめ。オーディオ／MIDIデバイスを選ぶだけで、すぐにパッドを試せます。

画面構成

メイン画面は大きく分けて、上部のヘッダー、左のパッドグリッド、右のエディタ、下部のフッターで構成されます。各部の役割を番号で確認しましょう。

04 Quick Start

クイックスタート

5つのステップで、空のキットから自分だけのドラムキットを作り上げる流れを体験しましょう。

Step 1

サンプルを読み込む

Finder / エクスプローラーから音声ファイル（WAV / AIFF / FLAC / MP3 など）をパッドへドラッグ＆ドロップ。または右クリック →「Load Sample…」で選びます。

Step 2

再生範囲を整える

波形上の START / END ハンドルで鳴らす範囲を決め、FADE でクリックノイズを除去。SMART TRIM で頭の無音を自動カットできます。

Step 3

鳴り方を決める

PLAYBACK タブで Volume / Pan / Pitch、再生モード（One Shot / Gate）、Choke、発音数を設定します。

Step 4

音を磨く

DYNAMICS でベロシティの反応を、FX で EQ・コンプ・サチュレーションなどを加えて質感を仕上げます。

Step 5

ミックス＆保存

MIXER で音量バランスと出力を整え、SAVE KIT AS で自分のキットとして保存します。

Ready

完成！

あとは MIDI で叩くだけ。パッドのMIDIノート（既定 C1〜）に合わせて打ち込み、トラックを鳴らしましょう。

NOTE パッドをクリックすると、選択と同時にサンプルが試聴されます（プリファレンスでオフにも可能）。波形上には再生位置を示すプレイヘッドが走ります。

05 Pads

パッドグリッド

画面左に並ぶ16個のパッドが、ASTER Drum Lab の中心です。3つのバンク（A / B / C）を合わせて、合計48パッドを扱えます。

基本操作

  • 選択／試聴：パッドをクリックすると選択され、音が試聴されます。
  • バンク切替：上部の A / B / C で16パッドのセットを切り替えます。
  • 読み込み：音声ファイルをパッドへドラッグ＆ドロップ。
  • 入れ替え：パッドを別のパッドへドラッグすると、音色を入れ替えます。
  • Mute / Solo：各パッドの M / S ボタンで個別に制御。

パッドの表示情報

表示意味
番号パッド番号（01〜16 / バンク内）
名前パッド名（クリックで変更可）
サンプル名読み込み中のファイル名
MIDIノートこのパッドを鳴らす音名（例：C1）
カラー帯パッドの識別カラー
TIP パッドの色は右クリック →「Change Pad Color…」から、9色のプリセットまたはカスタムカラーで自由に設定できます。キックは赤、ハットは水色…のように役割ごとに色分けすると視認性が上がります。

07 Layers

レイヤー

1つのパッドには最大8つのレイヤーを重ねられます。複数のサンプルを同時に鳴らして音に厚みを出したり、ベロシティ（叩く強さ）で鳴らすレイヤーを切り替えたりできます。

レイヤーの操作

  • MAIN が基本レイヤー。追加すると L2, L3 … と並びます。
  • ＋（ADD LAYER）で追加、各タブの × で削除。
  • レイヤー名をクリックで選択。編集対象が切り替わります。
  • 各レイヤーに M / S（ミュート／ソロ）があります。
  • 波形・TRIM・PLAYBACK・DYNAMICS・FX は選択中レイヤーに適用されます。

ベロシティ・レイヤリング

2つ以上のレイヤーがあるとき、PLAYBACKタブに VEL RANGE が表示されます。各レイヤーに発音するベロシティ範囲（0〜127）を割り当てることで、

  • 弱打 → ソフトなサンプル、強打 → 鋭いサンプル
  • といった強弱で音色が変わるリアルな表現が可能です。

SPLIT は全レイヤーへ範囲を均等分割、AUTO は追加時に自動で範囲を割り当てます。

TIP 重ねたレイヤーは PLAYBACK の PHASE（Ø） で位相反転できます。キックのサブレイヤーなどで音が薄く感じるときに試すと、芯が出ることがあります。

09 Editor — Trim

TRIM タブ

再生範囲とフェードを数値ノブで精密に設定するタブです。波形上のハンドル操作と連動します。

パラメータ範囲説明
START0 – 100 %再生を開始する位置。頭の不要部分をカットします。
END0 – 100 %再生を終了する位置。末尾の不要部分をカットします。
FADE IN0 ms –立ち上がりのフェード。アタックのクリックノイズを除去します。
FADE OUT0 ms –終わりのフェード。プツッという切れを防ぎます。
NOTE すべてのノブは Option/Alt＋クリック で初期値に戻り、値の表示をダブルクリックすると数値を直接入力できます。これは ASTER Drum Lab のすべてのノブ・フェーダーに共通の操作です。
TIP ループ素材やワンショットの頭出しは、まず SMART TRIM（波形エディタ）で大まかに合わせ、TRIMノブで微調整すると速くて正確です。

10 Editor — Playback

PLAYBACK タブ

音量・パン・ピッチといった基本から、再生モード、チョーク、発音数（ポリフォニー）まで、パッドの「鳴り方」を決めるタブです。

レベルとピッチ

名称範囲
VOLUME−∞ – 0 dB +
PANL ↔ C ↔ R
PITCH−24 – +24 st
PHASE (Ø)位相反転
OUTPUT出力アサイン

再生モード（MODE）

One Shotキーを離しても最後まで再生
Gate押している間だけ再生

CHOKE（チョークグループ）

同じチョークグループ（1〜4）に属するパッドは、片方を鳴らすともう片方が止まります。クローズ／オープンハイハットの鳴き分けに最適です。OFF で無効。

VOICES（発音数）＆ STEAL

VOICES はこのパッドの同時発音数（1 / 2 / 4 / 8 / 16 / ∞）。上限に達したときの挙動を STEAL で選びます。

OLD最も古い音を止める
QUIET最も小さい音を止める
OFF新しい音を鳴らさない
TIP VEL RANGE（マルチレイヤー時のみ表示）で、レイヤーごとに反応するベロシティ範囲を設定できます。詳しくは「07. レイヤー」を参照してください。

11 Editor — Dynamics

DYNAMICS タブ

エンベロープと、演奏の強弱（ベロシティ）への反応を設定します。打ち込みに人間らしいニュアンスを加えるのに役立ちます。

パラメータ範囲説明
ATTACK0 – 2000 ms音の立ち上がりの速さ。長くするとソフトな入りに。
RELEASE0 – 4000 ms発音終了後の余韻の長さ。
HUMANIZE0 – 100 %発音ごとに音量・タイミングを微妙に揺らし、機械的な反復を緩和。
VELOCITY0 – 100 %ベロシティ感度。0%でベロシティを無視（一定音量）、100%で最大限反応。
VEL CURVEプリセット / Customベロシティ→音量の変換カーブ。

VEL CURVE プリセット

Linear

入力をそのまま反映（標準）。

Soft

弱打でも音量が出やすい。

Hard

強く叩いたときだけ大きく。

Less Dynamics

音量差を圧縮し均一に。

More Dynamics

音量差を強調しメリハリ。

Custom

カーブ上の2点をドラッグして自作。

TIP 打ち込みが単調に聞こえるときは、HUMANIZE を 5〜15% ほど加えるだけで、ハイハットやシェイカーの連打が一気に生っぽくなります。

12 Editor — FX

FX タブ — 操作

各レイヤーは独立したFXチェーンを持ちます。EQ・フィルター・ドライブ・トランジェント・コンプの5種類を、自由な順番で組み合わせられます。

チェーンの編集

  • ＋ Add FX でモジュールを追加（各タイプ1つまで／レイヤー）。
  • 左端のハンドルをドラッグして処理順を入れ替え。
  • 電源アイコンでバイパス、× で削除。
  • モジュールを右クリックで設定の Copy / Paste / Reset。
NOTE FXはレイヤーごとに独立しています。マルチレイヤーのパッドでは、レイヤーを切り替えるとそのレイヤー専用のFXチェーンが表示されます。処理は左から右の順に適用されます。
✦ ASTER Drum Lab — User Manual13
13 Editor — FX

FX タブ — 5種のFX

それぞれのFXモジュールの役割と主なパラメータです。ドラムの整音に必要な処理を一通り内蔵しています。

◆ EQ — 4バンド・イコライザー

バンド種類用途
LOWShelf / Cut低域のブースト／カット。芯や重さを調整。
LOW MIDBellこもり（200〜500Hz付近）の処理。
HIGH MIDBellアタックや存在感（2〜4kHz）を強調。
HIGHShelf / Cut高域の明るさ・空気感を調整。

各バンドは FREQ（周波数）/ GAIN（増減）/ Q（幅） を持ちます。カーブを直接ドラッグして編集することも可能です。

◆ FILTER

独立したハイパス（HP）とローパス（LP）。スロープは 12 / 24 / 48 dB/oct、レゾナンスも各々設定可。両方を有効にするとバンドパス的に使えます。

◆ DRIVE — サチュレーション

7種のキャラクター（Soft / Hard / Tube / Tape / Fold / Bit Crush / Rate）で歪み・質感を付加。DRIVE（量）/ TONE / MIX / OUTPUT で調整します。

◆ TRANSIENT

ATTACK でアタックの強さ、SUSTAIN で余韻を ±方向に調整。叩きを際立たせたり、逆にルームを抑えたりできます。

◆ COMPRESSOR

THRESHOLD−48 – 0 dB
RATIO1:1 – 20:1
ATTACK1 – 80 ms
RELEASE10 – 500 ms
MIX0 – 100 %
TIP 定番の流れは EQ → COMPRESSOR → DRIVE。まずEQで不要な帯域を整え、コンプで粒を揃え、最後にドライブで質感を足す——この順番を起点に、ハンドルドラッグで入れ替えながら追い込みましょう。

15 Mixer — Routing

出力モードとルーティング

ASTER Drum Lab は最大48の出力を備え、各パッドを個別のDAWチャンネルへ送れます。出力構成はミキサー上部に集約されています。

OUT MODE（出力モード）

モード内容
STEREOメインL/Rのみ（1ステレオ）
16 OUTS16系統の個別ステレオ出力
32 OUTS32系統の個別ステレオ出力
48 OUTS48系統＝全パッド個別出力

DAW側のマルチアウト構成と合わせて使います。各パッドの OUTPUT で送り先（例：1-2、3-4 …）を指定します。

ROUTING プリセット

ボタン動作
ALL MAIN全パッドをメイン出力(1-2)へ
INDIVIDUALPad1→Out1、Pad2→Out2…と連番で個別アサイン

RECALL保存したルーティングを呼び戻す

現在の状態は ALL MAIN / INDIVIDUAL / CUSTOM と表示されます。

NOTE マルチアウトを使うには、まずDAW側でASTER Drum Labをマルチアウトプット楽器として読み込み、補助（Aux）チャンネルを必要数立ち上げる必要があります。手順はお使いのDAWのマニュアルをご確認ください。
TIP まず INDIVIDUAL で全パッドをバラ出しし、不要なものだけ OUTPUT で個別にメインへ戻す——という進め方が効率的です。固まったら SAVE CUSTOM で控えておくと安心です。

キット管理

作り込んだ48パッドの構成は「キット」として保存・読み込みできます。ヘッダーの KIT セレクタと SAVE ボタンが入口です。

保存と読み込み

操作内容

19 Help

トラブルシューティング

よくある質問と対処法です。解決しない場合はサポートまでお問い合わせください。

Q. 音が鳴らない

  • パッドにサンプルが読み込まれているか確認（「— empty —」になっていないか）。
  • パッドの MIDIノートと、打ち込み／鍵盤のノートが一致しているか。
  • パッドまたはレイヤーが Mute、あるいは他に Solo がないか。
  • マスター OUTPUT が下がりきっていないか、DAWのトラック出力先が正しいか。

Q. サンプルが「Missing」と表示される

元のファイルが移動／削除された状態です。MISSING タブまたはパッドの RELINK から、ファイルを選び直してください（同名ファイルはまとめて解決されます）。

Q. マルチアウトの音がDAWに出てこない

  • プラグインをマルチアウトプット構成で読み込んでいるか。
  • OUT MODE が Stereo 以外（16/32/48 Outs）になっているか。
  • 各パッドの OUTPUT アサインと、DAWのAuxチャンネルの入力が対応しているか。

Q. CPU負荷が高い

  • 不要なFX（特にコンプ／フィルターの高スロープ）をバイパス／削除する。
  • レイヤー数や同時発音数（VOICES）を見直す。
  • フッターの CPU メーターで負荷を確認しながら調整する。
